# 実在部品の図面と、本モデルの仮定を突き合わせた結果

> この文書の HTML 版（同名 `.html`）は `npm run docs:html` で生成しています。**HTML を直接編集しないでください。**

作成 2026-08-02 ／ 成果物 `artifacts/real_jack_comparison.json`（`npm run compare:real-jack`）

---

## 0. 結論を先に

**このプロジェクトの看板だった結論は、見つかった唯一の実在図面には支持されませんでした。**

4極ジャックの接点位置には一次資料が 1 つもなく、4 件とも仮定でした（[UNKNOWNS.md](../UNKNOWNS.md) §5-2）。
これを資料で埋められないか **170 型番**を実際に開いて探し、**接点位置そのものが寸法記入された図面を 1 件**見つけました。
その値を本モデルへ入れると、

| | 深さ 12.9〜13.1 mm 付近 |
|---|---|
| 仮定値（1.25 / 4.35 / 7.35 / **11.4**） | 左右差分が残る区間が出る（幅 0.23 mm） |
| 図面値（1.28 / 4.4 / 7.55 / **12.75**） | **区間が出ない**（全ストロークで 1 点も無い） |

3 件はほぼ一致しました（差 0.03 / 0.05 / 0.20 mm）。**外れたのは Tip 接点 1 件だけで、その 1 件が結論を決めていました。**

> **同日の続報で、この結論はさらに 1 段変わりました（→ §6）。**
> Lumberg 自身の 4極ジャック **1503 28** を読むと、Tip ばねの**端子**は 11.30 mm にあり、
> それを接点位置として計算すると**区間は出ます**（13.30〜13.52 mm）。
> つまり **「唯一の実在図面が否定した」ではなく「実在資料 2 件が逆を指している」**が正確です。
> 2 件は証拠の種類が違います（PS000001 = 接点そのもの／1503 28 = 端子）。
> 以下の §1〜§4 は PS000001 単独の話として読んでください。

## 2. その図面が信用できるかを、先に確かめました

寸法が書いてあっても、図が縮尺どおりでなければ読み違えます。
そこで**図面の中に描かれているプラグ**を使って照合しました。

断面図を 800 dpi で描画し、Reference plane を 0・`12.75` の寸法線終端を基準に px/mm を求めて、
**プラグの絶縁帯 3 本の中心位置**を読み取りました。**自動計測ではなく目視の読み取りで、精度はおよそ 0.1 mm です。**

| | 絶縁帯 1 | 絶縁帯 2 | 絶縁帯 3 |
|---|---:|---:|---:|
| 図面から読み取り | 2.76 | 5.79 | 8.80 |
| 本モデルが計算する値 | 2.85 | 5.85 | 8.85 |

**最大 0.09 mm の差でした。これは読み取り精度と同程度なので、「ずれが無い」と読むべきです。**
逆に言うと、**この照合で言えるのは 0.1 mm の粒度まで**です。

本モデルのプラグ導体境界は、独立した 2 社の図面から得た FACT です（[SOURCES.md](../SOURCES.md) §9）。
そこと合うということは、次の 2 つが同時に言えます。

1. この断面図は**縮尺どおりに描かれている**
2. 図中のプラグは**完全挿入の状態**で描かれており、`Reference plane` は
   **完全挿入時にプラグ肩が来る面** ＝ 本モデルの深さ基準と同じ

つまり **座標系が一致している**ので、図面の 4 値をそのまま本モデルへ入れて比較できます。

## 3. 何が起きて、なぜ消えるのか

### 3-1. 消え方

| 深さ | 仮定値のとき | 図面値のとき |
|---:|---|---|
| 12.90 | L=Tip / R=Ring / GND=浮き → **左右差分** | L=**届かず** / R=Ring / GND=Ring |
| 13.00 | L=Tip / R=Ring / GND=浮き → **左右差分** | L=**届かず** / R=Ring / GND=浮き → 無音 |
| 13.20 | L=Tip / R=Ring / GND=Sleeve → 正常 | L=**届かず** / R=Ring / GND=Sleeve → 片側のみ |
| 13.40 | 正常 | 正常 |

**帰線が浮く区間そのものは、図面値でも残っています。**
消えるのは「そのとき L も生きている」という条件のほうです。
Tip 接点が 1.45 mm 奥へ動いたため、帰線が浮く深さに達しても
**Tip 接点はまだプラグ先端の円錐部にしか届いておらず、L が生きません。**
判定は左右差分ではなく無音になります。

### 3-2. しきい値

Tip 接点の軸位置だけを 0.05 mm 刻みで振ると、境目がはっきり出ます。

| Tip 接点の軸位置 | 左右差分の区間 |
|---:|---|
| 〜 **12.60 mm** | 出る |
| **12.65 mm** 〜 | **出ない** |

図面値 12.75 は、**しきい値の 0.15 mm 向こう側**です。

**看板の結論は「Tip 接点が 12.6 mm より浅いこと」を必要条件にしていました。**
これは今回まで書かれていなかった条件です。

### 3-3. 他の軸では戻りません

図面の 4 値を固定したまま、パッド幅（0.3〜0.9 mm）と接触ドームの追従量（0.02〜0.15 mm）を
総当たり 20 通り振りましたが、**1 通りも区間は戻りませんでした**。
Tip 接点の位置が単独で効いています。

### 3-4. 図面値のほうが「もっともらしい」

12.75 mm は、プラグ側で見ると s = 14 − 12.75 = **1.25 mm** の位置です。
本モデルの図面実測では、プラグ先端の円錐は **s = 1.296 mm** で終わって外径が最大になります。

**実在部品は、Tip 導体に触れられる最も手前で当てています。**
一方、本モデルの仮定 11.4 mm（s = 2.6）は Tip 導体の真ん中でした。
図面値は恣意的な数字ではなく、設計上の意味がある位置です。

## 4. 差し替えも variant 追加もしません

**採用: 比較対象として持つ（compare-only）**

| 選択肢 | 採らなかった理由 |
|---|---|
| 仮定値を図面値で**差し替える** | 図面にあるのは接点の軸位置 4 件だけです。パッド幅・ばね定数・端子配置・ブレーク接点は図面にありません。4 件だけ入れ替えると、**残りが仮定のままなのに「実在部品の値」を名乗る**ことになります |
| **新しい variant** として足す | 同じ理由です。足りない諸元を今の仮定で埋めることになり、**部品の形をした別物**ができます。公開済みの artifact と Half-Plug profile が参照している構成も静かに変わります |

いま確実に言えるのは値そのものではなく、**しきい値と反例**です。

- 看板の結論には「Tip 接点が 12.6 mm より浅い」という**必要条件**がある
- 見つかった唯一の実在図面は、**その条件を満たさない**

この 2 つを artifact（`artifacts/real_jack_comparison.json`）とテストで固定しました。
将来この結論を復活させる変更が入っても、テストが落ちます。

> **この 1 件で「4極ジャック一般」は語れません。**PS000001 は防水 SMT 品 1 部品です。
> 別の部品では Tip 接点がもっと手前にあるかもしれません。
> 言えるのは「少なくとも 1 つの実在設計では成立しない」ということです。

## 5. 探した範囲（見つからなかった方向も残します）

「探したが無かった」と「探していない」は別の情報です。
2026-08-02 に **13 方面・170 型番**を実際に開いて確認しました。

| 方面 | 確認 | 当たり | うち**接点位置** |
|---|---:|---:|---:|
| Same Sky Devices（旧 CUI） | 11 | 9 | 0 |
| Cliff Electronics | 12 | 8 | 0 |
| Kycon | 20 | 9 | 0 |
| Switchcraft | 10 | 6 | 0 |
| Würth Elektronik | 7 | 0 | 0 |
| 日本メーカー（Hosiden / SMK / Alps / JAE / Hirose） | 14 | 4 | 0 |
| Amphenol / TE / Molex / CONEC / **Lumberg** | 17 | 8 | 0 |
| 汎用中国製（PJ-320 系ほか） | 12 | 10 | 0 |
| **流通（Digi-Key / Mouser / Farnell ほか）** | 13 | 7 | **1** |
| 3D CAD（STEP / IGES） | 19 | 3 | 0 |
| 規格（JEITA RC-5325A / JIS C 6560） | 8 | 1 | 0 |
| 特許 | 14 | 2 | 0 |
| 第三者の実測・分解記事 | 13 | 6 | 0 |
| **合計** | **170** | **73** | **1** |

> **「当たり」の中身は一様ではありません。** 大半は基板レイアウト図の**端子位置**（クラス B）ですが、
> 3D CAD の 3 件は STEP の配布があるという意味、規格の 1 件と特許の 2 件は別種の手がかりです。
> **接点位置そのものが寸法記入されていたのは 1 件だけ**という点だけが、方面をまたいで一様です。

### 分かったこと

- **端子の位置なら、どこでも手に入ります。** メーカー・流通・汎用品を問わず、
  基板レイアウト図に挿入軸方向の端子位置が入っていました（当たり 73 件の大半）。
- **しかし端子の位置から接点の位置は出せません。**3極の Lumberg 1503 09 では
  「端子＝接点ばねの根元、ばねは前方へ伸びる」と読めましたが、
  **実在の 4極品ではこれが成り立ちません。**Cliff FC68125 を自分で読むと、
  本体前面基準で **Tip 端子 = 3.4 / Ring1・Ring2 端子 = 11.5 / Sleeve 端子 = 12.4 mm** です。
  接点は必ず「開口に近い順に Sleeve → Ring2 → Ring1 → Tip」でなければならないので、
  **端子の並びは接点の並びと逆**になっています。同じ逆転は Same Sky SJ-43514 / SJ3-35044A でも見ました。
- **規格からは取れません。** JEITA RC-5325A（4極）は有償・非公開で、無償サンプルは付図に届きません。
  JIS C 6560 は公開ミラーで読めましたが、2極・3極のみで、内部接点の寸法記入はありません。
- **Würth Elektronik はオーディオジャックを作っていません。** 探索前提が誤りでした（同社カタログで確認）。
- 5極ジャックの特許 **US9774152B2** の FIG.5 が、ジャック外端面基準の接点位置を寸法記入しています。
  ただし**明細書本文で確認できたのは 10.0 mm（Ring 3 spring）1 件だけ**で、残りは図中にしかなく、
  Google Patents が 503 / patentimages が 403 で図を取得できませんでした。
  しかも 5極の**推奨値**であって出荷部品の実測ではありません。二次的な傍証として扱います。

### 探索の限界

- **13 方面は網羅ではありません。** 台湾・韓国メーカー、車載向け、日本メーカーの個別品番カタログは
  十分に当たれていません。
- 図面がラスタ画像でテキスト抽出できないものは、レンダリングして目視で読みました。
  **寸法の数字そのものは図に書かれているので読み違えにくい**一方、
  §2 の照合のような「図から位置を測る」作業は目視なので 0.1 mm 程度の誤差を含みます。本命の PS000001 と Cliff FC68125 / FC68129 については、
  **上記のとおり自分で PDF を取得し、図を描画して確認しています。**

> **付記（2026-08-02）:** [SOURCES.md](../SOURCES.md) §9 で挿入口径の根拠として引いていた
> **Cliff FC68128 は「3.5mm PHONE JACK - 4 POLE (17mm PLUG)」** で、嵌合長 17 mm の別規格品でした。
> 挿入口径 Ø3.6 の根拠としては有効ですが、**14 mm プラグの部品として扱ってはいけません。**

## 6. Lumberg の 4極品を読みました（2026-08-02 追記）

Lumberg は 3.5mm 4極の**対応組み合わせ**を持っています。本プロジェクトの 3極は
Lumberg 1532 10 / 1503 09 の対で組んであるので、同じ品質で 4極を組み直せる可能性がありました。

| | 部品 | 規格 |
|---|---|---|
| プラグ | **1532 02** | JEITA RC-5325A **JC35P4** |
| ジャック | **1503 28** | JEITA RC-5325A・ブレーク接点 2 個・SMT |

両方のデータシートを取得して図面を読みました。

### 6-1. プラグ 1532 02 — 導体境界の寸法が**ありません**

図面にある寸法は **`14` / `25` / `12` と `ø3.5`** だけです。
3極の 1532 10 が持っていた `8.5` / `5` / `0.7` に相当するものがなく、
**独立した 3 社目の「記載寸法」にはなりませんでした。**

ただし図は縮尺どおりに描かれています。1200 dpi で描画して寸法補助線を検出すると、
**3 区間とも 67.0 px/mm** で一致しました（`14`→67.00 / `25`→67.12 / `12`→67.00）。
そこで [SOURCES.md](../SOURCES.md) §5 と同じ手法で導体境界を実測しました。

| 区間 | 図面実測 | 本モデルの FACT |
|---|---:|---:|
| Tip | 0〜5.02 | 0〜4.8 |
| 絶縁帯 1 | 5.02〜5.64 | 4.8〜5.5 |
| Ring1 | 5.64〜8.03 | 5.5〜7.8 |
| 絶縁帯 2 | 8.03〜8.51 | 7.8〜8.5 |
| Ring2 | 8.51〜11.02 | 8.5〜10.8 |
| 絶縁帯 3 | 11.02〜11.49 | 10.8〜11.5 |
| Sleeve | 11.49〜**14.000** | 11.5〜14.0 |

**合計は 14.000 mm でぴたりと閉じます。**構成（導体 4・絶縁帯 3・その並び）は一致し、
Sleeve 長 2.507 は記載値 2.5 と一致します。

> **ただしこの実測は精度が足りません。** 図面の線幅が 0.239 mm あり、
> 境界を線の中心で取るか外縁で取るかで **±0.12 mm** 動きます。
> 絶縁帯幅は中心間で 0.48、線幅を足すと 0.72 で、**記載値 0.7 と区別できません。**
> つまりこの実測は「**構成が同じことの確認**」であって、
> **0.7 という数値の独立した裏付けにはなりません。**

### 6-2. ジャック 1503 28 — 端子と回路構成は読めます。接点位置は読めません

図面に断面図はなく、基板レイアウトと回路記号までです。

**回路記号**（箱＝バレル）:

```
端子1 ─ 箱（Sleeve バレル）
端子2 ─ ばね（ブレーク接点なし）
端子3 ─ ばね ─ 常時 端子5 に接触
端子4 ─ ばね ─ 常時 端子6 に接触
```

3極の 1503 09 とまったく同じ構造です（箱が 1 つ、信号ばね 2 本にブレーク接点）。
**「ブレーク接点 2 個」はデータシート本文の記載とも一致します。**

**端子の軸位置**（基板レイアウト。ノーズ突出 2.00 を足して挿入口面基準に換算）:

| 端子 | 図面値 | 挿入口面基準 |
|---|---:|---:|
| 1（箱＝Sleeve）／ 2 | 2.75 | **4.74** |
| 3 | 5.50 | **7.50** |
| 4 | 9.30 | **11.30** |
| 5 | 10.50 | 12.50 |
| 6 | 11.50 | 13.50 |

### 6-3. 端子位置が、接点が入るべき範囲に**全部入っています**

完全挿入で各接点が正しい導体に乗るには、軸位置が次の範囲になければなりません。

| 接点 | 必要な範囲 | ばねの端子位置 |
|---|---|---:|
| Ring2 | 3.2〜5.5 | **4.74** ✓ |
| Ring1 | 6.2〜8.5 | **7.50** ✓ |
| Tip | 9.2〜14.0 | **11.30** ✓ |

**3 本とも入っています。**Cliff FC68125 のように端子の並びが接点の並びと逆なら、
こうはなりません。この部品では**接点が端子のほぼ真上にある**と読むのが自然です。

そこで「接点＝端子位置」として計算すると:

- 完全挿入は正常（MIC→Sleeve / L→Tip / R→Ring / GND→Sleeve）
- **左右差分の区間が出ます: 13.30〜13.52 mm（幅 0.22 mm）**

> **刻みによって 0.01〜0.02 mm ずれます。**成果物 profile は 0.02 mm 刻みの走査なので
> 13.30〜13.52、`npm run compare:real-jack` は 0.01 mm 刻みなので 13.29〜13.50 を出します。
> **本文では profile の値（受け渡す値）に揃えています。**
> profile 自身も `uncertainty.boundaryResolutionMm: 0.02` として境界の粒度を記録しています。

### 6-4. 実在部品 2 件が、逆を向いています

| 根拠 | Tip 接点の軸位置 | 左右差分の区間 | 根拠の強さ |
|---|---:|---|---|
| ~~本モデルの旧仮定~~ | ~~11.4~~ | ~~12.89〜13.11~~ | 一次資料なし（**2026-08-02 に退役**） |
| **PS000001**（**接点**の寸法記入） | **12.75** | **なし** | 断面図に直接記入。ただし商社ブランドで製造者不明 |
| **Lumberg 1503 28**（**端子**位置）**← 現在のモデル** | **11.30** | **13.30〜13.52** | メーカー公式・JEITA 準拠。ただし端子であって接点ではない |

**この 2 件は種類の違う証拠です。**

- PS000001 は**接点そのもの**の位置を書いています。強い。ただし 1 部品で、製造者も不明です。
- 1503 28 は**端子**の位置です。接点位置として使うのは推論であり、
  実在の 4極品にはその推論が成り立たないもの（Cliff FC68125）が現にあります。

したがって **「区間は出る」とも「出ない」とも言えません。**
言えるのは、**現象の成否が Tip 接点の軸位置 1 点にかかっており、
手に入る 2 件の実在資料が逆を指している**ということです。

前節（§0〜§4）で「実在図面 1 件に支持されていない」と書きましたが、
**より正確には「実在資料 2 件が割れている」です。**

## 7. 4極モデルを Lumberg 品へ組み直すか → **組み直しました（2026-08-02）**

**判断: 組み直す価値がある。独立した変更として実施した。**

### 何が変わるか

| 項目 | 現在 | 1503 28 ベース後 |
|---|---|---|
| ジャック外形・ボア ø3.6 | 一次資料なし | **FACT** |
| 端子の軸位置 6 本 | 定義なし | **FACT** |
| 端子番号 ↔ 機能 | 定義なし | **DERIVED**（1503 09 と同じ幾何的導出） |
| ブレーク接点の有無・個数 | **未定義**（[UNKNOWNS.md](../UNKNOWNS.md) §5-3） | **FACT**（2 個・回路記号あり） |
| 接点の軸位置 4 件 | ASSUMPTION（自由に選べる） | **ASSUMPTION（端子位置に拘束される）** |
| パッド幅・ばね定数 | ASSUMPTION | ASSUMPTION（変わらない） |

**§5-2 は閉じません。**接点位置は仮定のままです。
変わるのは「4 件を自由に選んだ」から「実在部品の端子位置に縛られた」への格上げと、
**§5-3（ブレーク接点）が完全に解決する**ことです。

### やらなかったこと

**外形は 3極 1503 09 の値を流用したままです。**組み直したのは接点系だけで、
ハウジング寸法・ノーズ長・ナット径は変えていません。
1503 28 は SMT のミッドマウント品でナットを持たないので、**3D 表示の外形は実物と違います。**
これは接点系だけを実在部品に合わせた合成であり、1503 28 の再現ではありません。

## 8. 外形は揃えませんでした（2026-08-02 の判断）

§7 で接点系を 1503 28 へ移しましたが、**外形（本体・ノーズ・ナット）は 3極 1503 09 の
流用のままにしています。**その判断の記録です。

### 図面からは読めました

| 項目 | 1503 28 の記載値 | 本モデル（1503 09 流用） |
|---|---|---|
| 全長 | **14.00** | 17.6 |
| ノーズ | 長さ **2.00** / **ø5.00** | 長さ 3.5 / ø6 |
| 挿入口 | **ø3.60±0.1** | ø3.6（同じ） |
| 本体幅 | **7.50**（つば込み 9.10） | 11.5 |
| 本体高さ | **4.20** | 6 |
| 実装 | **SMT ミッドマウント**（パッド 6 本・2 列） | スルーホール・パネル取付（はんだ穴 5 本） |

**寸法だけなら差し替えられます。**それでも揃えなかった理由は 4 つです。

### 1. 基板面からの軸高さが読み取れない

これが決定的でした。`jack.housing.axisHeightFromPcb` は 3D の配置に必須ですが、
**1503 28 はミッドマウント品で、基板が本体の途中を通ります。**
3極品のような「基板の上に載っていて、その面から軸まで何 mm」という量になりません。
図面の正面図にある `4.20` と `1.50` からどちらとも読めて、**確定できませんでした。**

推測で埋めれば 3D は動きますが、**根拠タブに区分と出典つきで表示される数値**なので、
このプロジェクトでそれをやるわけにはいきません。

### 2. 寸法だけ入れ替えると、かえって嘘が増える

3D は前面の円柱を `materials.json` の **「ローレットナット (CuZn ニッケルめっき)」**として描きます。
1503 28 のノーズは**樹脂（PA GF）**で、ナットではありません。
材質の割り当ては variant 別に切り替えられる構造になっていないので、
**寸法だけ 1503 28 にすると「1503 28 の形をした、金属ナットつきの何か」**になります。

いまの「見るからに 3極品の外形を借りている」状態のほうが、読者を誤らせません。

### 3. 端子の形が違う

1503 28 は SMT パッド 6 本（2 列）、1503 09 はスルーホール 5 本です。
`jackGeometry.ts` は端子を 1 列の脚として置いており、これも構造の変更になります。

### 4. 外形は計算に一切入らない

接触判定・回路・力は、プラグの軸方向区間と接点の軸位置・パッド幅・ばね変位だけで決まります。
**外形は表示専用**です。揃えても結論は 1 つも変わりません。

- **アプリの variant 説明文を直しました。**「端子番号は Same Sky SJ3-35074A に準拠」という
  組み直し前の文言が残っていたので、1503 28 ベースであること・**外形は流用であること**を
  画面上に出しています
- [UNKNOWNS.md](../UNKNOWNS.md) §5-6 に、軸高さが読めない件を立てました
