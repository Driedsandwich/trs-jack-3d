# 実在部品の図面と、本モデルの仮定を突き合わせた結果

> この文書の HTML 版（同名 `.html`）は `npm run docs:html` で生成しています。**HTML を直接編集しないでください。**

作成 2026-08-02 ／ 成果物 `artifacts/real_jack_comparison.json`（`npm run compare:real-jack`）

---

## 0. 結論を先に

**このプロジェクトの看板だった結論は、見つかった唯一の実在図面には支持されませんでした。**

4極ジャックの接点位置には一次資料が 1 つもなく、4 件とも仮定でした（[UNKNOWNS.md](../UNKNOWNS.md) §5-2）。
これを資料で埋められないか **170 型番**を実際に開いて探し、**接点位置そのものが寸法記入された図面を 1 件**見つけました。
その値を本モデルへ入れると、

| | 深さ 12.9〜13.1 mm 付近 |
|---|---|
| 仮定値（1.25 / 4.35 / 7.35 / **11.4**） | 左右差分が残る区間が出る（幅 0.23 mm） |
| 図面値（1.28 / 4.4 / 7.55 / **12.75**） | **区間が出ない**（全ストロークで 1 点も無い） |

3 件はほぼ一致しました（差 0.03 / 0.05 / 0.20 mm）。**外れたのは Tip 接点 1 件だけで、その 1 件が結論を決めていました。**

## 1. 見つけた資料

| 項目 | 内容 |
|---|---|
| 部品番号 | **PS000001** |
| ブランド | pro-SIGNAL（Premier Farnell の自社ブランド） |
| 製造者 | **図面に記載なし**（商社の自社ブランド資料） |
| 文書名 | 3.5mm 4 Pole Audio Jack, SMT, IPX5/7 |
| 発行 | 2017-03-31 V1.0 |
| URL | https://www.farnell.com/datasheets/2261829.pdf |
| 取得日 | 2026-08-02 |

図面の `SEC:A-A` が **4極プラグを挿した状態の断面図**（"Image of plug match with contact point"）で、
図中の `* Reference plane` から各接点ばねへ引出線を引き、
**1.28 / 4.4 / 7.55 / 12.75 mm** と 4 接点すべてが寸法記入されています。

**探した 170 型番のうち、接点位置そのものが寸法記入されていたのはこの 1 件だけです。**
残りはすべて「はんだ端子の位置」まで（→ §4）。

> **信頼度は「メーカー公式図面」ではありません。**[SOURCES.md](../SOURCES.md) の格付けでは
> 4 番目の「部品商社資料」にあたります。製造者名が書かれていないため、
> 一次資料としての強さは Lumberg の図面に劣ります。

## 2. その図面が信用できるかを、先に確かめました

寸法が書いてあっても、図が縮尺どおりでなければ読み違えます。
そこで**図面の中に描かれているプラグ**を使って照合しました。

断面図を 800 dpi で描画し、Reference plane を 0・`12.75` の寸法線終端を基準に px/mm を求めて、
**プラグの絶縁帯 3 本の中心位置**を読み取りました。**自動計測ではなく目視の読み取りで、精度はおよそ 0.1 mm です。**

| | 絶縁帯 1 | 絶縁帯 2 | 絶縁帯 3 |
|---|---:|---:|---:|
| 図面から読み取り | 2.76 | 5.79 | 8.80 |
| 本モデルが計算する値 | 2.85 | 5.85 | 8.85 |

**最大 0.09 mm の差でした。これは読み取り精度と同程度なので、「ずれが無い」と読むべきです。**
逆に言うと、**この照合で言えるのは 0.1 mm の粒度まで**です。

本モデルのプラグ導体境界は、独立した 2 社の図面から得た FACT です（[SOURCES.md](../SOURCES.md) §9）。
そこと合うということは、次の 2 つが同時に言えます。

1. この断面図は**縮尺どおりに描かれている**
2. 図中のプラグは**完全挿入の状態**で描かれており、`Reference plane` は
   **完全挿入時にプラグ肩が来る面** ＝ 本モデルの深さ基準と同じ

つまり **座標系が一致している**ので、図面の 4 値をそのまま本モデルへ入れて比較できます。

## 3. 何が起きて、なぜ消えるのか

### 3-1. 消え方

| 深さ | 仮定値のとき | 図面値のとき |
|---:|---|---|
| 12.90 | L=Tip / R=Ring / GND=浮き → **左右差分** | L=**届かず** / R=Ring / GND=Ring |
| 13.00 | L=Tip / R=Ring / GND=浮き → **左右差分** | L=**届かず** / R=Ring / GND=浮き → 無音 |
| 13.20 | L=Tip / R=Ring / GND=Sleeve → 正常 | L=**届かず** / R=Ring / GND=Sleeve → 片側のみ |
| 13.40 | 正常 | 正常 |

**帰線が浮く区間そのものは、図面値でも残っています。**
消えるのは「そのとき L も生きている」という条件のほうです。
Tip 接点が 1.35 mm 奥へ動いたため、帰線が浮く深さに達しても
**Tip 接点はまだプラグ先端の円錐部にしか届いておらず、L が生きません。**
判定は左右差分ではなく無音になります。

### 3-2. しきい値

Tip 接点の軸位置だけを 0.05 mm 刻みで振ると、境目がはっきり出ます。

| Tip 接点の軸位置 | 左右差分の区間 |
|---:|---|
| 〜 **12.60 mm** | 出る |
| **12.65 mm** 〜 | **出ない** |

図面値 12.75 は、**しきい値の 0.15 mm 向こう側**です。

**看板の結論は「Tip 接点が 12.6 mm より浅いこと」を必要条件にしていました。**
これは今回まで書かれていなかった条件です。

### 3-3. 他の軸では戻りません

図面の 4 値を固定したまま、パッド幅（0.3〜0.9 mm）と接触ドームの追従量（0.02〜0.15 mm）を
総当たり 20 通り振りましたが、**1 通りも区間は戻りませんでした**。
Tip 接点の位置が単独で効いています。

### 3-4. 図面値のほうが「もっともらしい」

12.75 mm は、プラグ側で見ると s = 14 − 12.75 = **1.25 mm** の位置です。
本モデルの図面実測では、プラグ先端の円錐は **s = 1.296 mm** で終わって外径が最大になります。

**実在部品は、Tip 導体に触れられる最も手前で当てています。**
一方、本モデルの仮定 11.4 mm（s = 2.6）は Tip 導体の真ん中でした。
図面値は恣意的な数字ではなく、設計上の意味がある位置です。

## 4. 差し替えも variant 追加もしません

**採用: 比較対象として持つ（compare-only）**

| 選択肢 | 採らなかった理由 |
|---|---|
| 仮定値を図面値で**差し替える** | 図面にあるのは接点の軸位置 4 件だけです。パッド幅・ばね定数・端子配置・ブレーク接点は図面にありません。4 件だけ入れ替えると、**残りが仮定のままなのに「実在部品の値」を名乗る**ことになります |
| **新しい variant** として足す | 同じ理由です。足りない諸元を今の仮定で埋めることになり、**部品の形をした別物**ができます。公開済みの artifact と Half-Plug profile が参照している構成も静かに変わります |

いま確実に言えるのは値そのものではなく、**しきい値と反例**です。

- 看板の結論には「Tip 接点が 12.6 mm より浅い」という**必要条件**がある
- 見つかった唯一の実在図面は、**その条件を満たさない**

この 2 つを artifact（`artifacts/real_jack_comparison.json`）とテストで固定しました。
将来この結論を復活させる変更が入っても、テストが落ちます。

> **この 1 件で「4極ジャック一般」は語れません。**PS000001 は防水 SMT 品 1 部品です。
> 別の部品では Tip 接点がもっと手前にあるかもしれません。
> 言えるのは「少なくとも 1 つの実在設計では成立しない」ということです。

### 次にやるなら — Lumberg 1503 28

探索中に、**Lumberg 自身が 3.5mm 4極ジャックを出している**ことが分かりました。

| | |
|---|---|
| 部品 | **1503 28**（JEITA RC-5325A 準拠・4極・ブレーク接点 2 個・SMT） |
| 対応プラグ | **1532 02**（データシートの Counterparts 欄） |
| URL | https://downloads.lumberg.com/datenblaetter/en/1503_28.pdf |

本プロジェクトの 3極は 1532 10 / 1503 09 という Lumberg の対で組んであります。
**4極も同じ品質・同じ図面様式・同じ読み取り手順で組み直せます。**
ただし 1503 28 の図面にも**断面図はなく**、基板レイアウトの端子位置
（2.75 / 5.50 / 6.87 / 9.30 / 10.50 / 11.50 mm）までです。接点位置は依然として仮定になります。

## 5. 探した範囲（見つからなかった方向も残します）

「探したが無かった」と「探していない」は別の情報です。
2026-08-02 に **13 方面・170 型番**を実際に開いて確認しました。

| 方面 | 確認 | 当たり | うち**接点位置** |
|---|---:|---:|---:|
| Same Sky Devices（旧 CUI） | 11 | 9 | 0 |
| Cliff Electronics | 12 | 8 | 0 |
| Kycon | 20 | 9 | 0 |
| Switchcraft | 10 | 6 | 0 |
| Würth Elektronik | 7 | 0 | 0 |
| 日本メーカー（Hosiden / SMK / Alps / JAE / Hirose） | 14 | 4 | 0 |
| Amphenol / TE / Molex / CONEC / **Lumberg** | 17 | 8 | 0 |
| 汎用中国製（PJ-320 系ほか） | 12 | 10 | 0 |
| **流通（Digi-Key / Mouser / Farnell ほか）** | 13 | 7 | **1** |
| 3D CAD（STEP / IGES） | 19 | 3 | 0 |
| 規格（JEITA RC-5325A / JIS C 6560） | 8 | 1 | 0 |
| 特許 | 14 | 2 | 0 |
| 第三者の実測・分解記事 | 13 | 6 | 0 |
| **合計** | **170** | **73** | **1** |

> **「当たり」の中身は一様ではありません。** 大半は基板レイアウト図の**端子位置**（クラス B）ですが、
> 3D CAD の 3 件は STEP の配布があるという意味、規格の 1 件と特許の 2 件は別種の手がかりです。
> **接点位置そのものが寸法記入されていたのは 1 件だけ**という点だけが、方面をまたいで一様です。

### 分かったこと

- **端子の位置なら、どこでも手に入ります。** メーカー・流通・汎用品を問わず、
  基板レイアウト図に挿入軸方向の端子位置が入っていました（当たり 73 件の大半）。
- **しかし端子の位置から接点の位置は出せません。**3極の Lumberg 1503 09 では
  「端子＝接点ばねの根元、ばねは前方へ伸びる」と読めましたが、
  **実在の 4極品ではこれが成り立ちません。**Cliff FC68125 を自分で読むと、
  本体前面基準で **Tip 端子 = 3.4 / Ring1・Ring2 端子 = 11.5 / Sleeve 端子 = 12.4 mm** です。
  接点は必ず「開口に近い順に Sleeve → Ring2 → Ring1 → Tip」でなければならないので、
  **端子の並びは接点の並びと逆**になっています。同じ逆転は Same Sky SJ-43514 / SJ3-35044A でも見ました。
- **規格からは取れません。** JEITA RC-5325A（4極）は有償・非公開で、無償サンプルは付図に届きません。
  JIS C 6560 は公開ミラーで読めましたが、2極・3極のみで、内部接点の寸法記入はありません。
- **Würth Elektronik はオーディオジャックを作っていません。** 探索前提が誤りでした（同社カタログで確認）。
- 5極ジャックの特許 **US9774152B2** の FIG.5 が、ジャック外端面基準の接点位置を寸法記入しています。
  ただし**明細書本文で確認できたのは 10.0 mm（Ring 3 spring）1 件だけ**で、残りは図中にしかなく、
  Google Patents が 503 / patentimages が 403 で図を取得できませんでした。
  しかも 5極の**推奨値**であって出荷部品の実測ではありません。二次的な傍証として扱います。

### 探索の限界

- **13 方面は網羅ではありません。** 台湾・韓国メーカー、車載向け、日本メーカーの個別品番カタログは
  十分に当たれていません。
- 図面がラスタ画像でテキスト抽出できないものは、レンダリングして目視で読みました。
  **寸法の数字そのものは図に書かれているので読み違えにくい**一方、
  §2 の照合のような「図から位置を測る」作業は目視なので 0.1 mm 程度の誤差を含みます。本命の PS000001 と Cliff FC68125 / FC68129 については、
  **上記のとおり自分で PDF を取得し、図を描画して確認しています。**

> **付記（2026-08-02）:** [SOURCES.md](../SOURCES.md) §9 で挿入口径の根拠として引いていた
> **Cliff FC68128 は「3.5mm PHONE JACK - 4 POLE (17mm PLUG)」** で、嵌合長 17 mm の別規格品でした。
> 挿入口径 Ø3.6 の根拠としては有効ですが、**14 mm プラグの部品として扱ってはいけません。**
