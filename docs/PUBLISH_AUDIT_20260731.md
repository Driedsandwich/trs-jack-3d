### git 履歴について

ファイルを直しただけでは、**過去のコミットの差分に実名が残ります。**
public にすると `git log -p` で誰でも読めるため、履歴そのものの書き換えが必要でした。

**対応済み（2026-07-31）**: 全コミットのツリーを走査して実名を「メンテナ」へ置換し
（`git filter-branch`）、force push しました。書き換え後に GitHub から新規クローンして、
**全差分・全コミットメッセージ・全ツリーで実名 0 件**を確認しています。
コミット構造とメッセージは保たれており、初回コミットは元から実名を含まないため無変更です。

**残る注意点**: GitHub は force push のあとも、到達不能になった古いコミットを
しばらく SHA 直指定で保持することがあります（実測で確認済み）。
このリポジトリは一度も public になっていないため古い SHA は外部に知られていませんが、
**完全に消したい場合はリポジトリを作り直すか、GitHub サポートへ purge を依頼する**必要があります。
本書に旧 SHA を書かないのも同じ理由です。
