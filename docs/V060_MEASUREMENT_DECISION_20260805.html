0. 推奨 — 条件付きで反転する（L の 1 点だけ自分で測る）

方針の理由（精度が要る）は、測定ごとに当てはまったり当てはまらなかったりします。 VERIFICATION_PLAN の各測定を、見分けたい差と要る技能の 2 つで並べ直しました。

測定見分けたい差分解能 0.01 mm に対して要る技能
§2-2 の L 1 点すき間 2.14 mm か 0.69 mm か145 倍導通が鳴った位置で止めて測るだけ
§2-2 の GND8.33 か 8.67 か34 倍同上
§1-1 プラグ外径直径差 0.30 / 0.23 / 0.090 の 3 本の線。隣り合う線の間隔は 0.07 mm7 倍逆テーパの頂点（先端から 4.3〜4.8 mm）を探して読む
§1-2 橋絡の決着光る／光らない（寸法ではない）—LED 回路の自作・プラグへのはんだ付け・一定速度での挿入
§2 深さの確認すき間—導通 + すき間（L と同種）
§2-2 の MIC / R0.03 / 0.05 mm3〜5 倍測っても差がつかない

L の 1 点だけは、145 倍離れた 2 つの予測のどちらかを選ぶ作業です。 ノギスを 0.1 mm 単位で雑に読んでも 14.5 倍あり、結論は動きません。 これは「精度の要る測定」ではありません。

一方 §1-1 は隣り合う判定線が 0.07 mm（7 倍）しかなく、しかも 逆テーパの頂点を自分で探す必要があります。当て方のクセがそのまま結論を変えます。 §1-2 は寸法ではありませんが、LED 回路を自作して一定速度で挿すという別の技能が要ります。 この 2 つは方針どおり「募集」のままにしてください。

条文にするなら 2 条件の AND を勧めます。

「自分で測る／測らない」を測定ごとに気分で決めると、いずれ精度の要る測定にも手が伸びます。

```

① 見分けたい差が、道具の分解能の 100 倍以上ある

② 道具の当て方・回路の自作・速度制御などの技能を要しない

```

L は ①②とも満たします。§1-1 は ① で落ち、§1-2 は ② で落ちます。

数で線を引けば、そこは毎回考えなくて済みます。

3. 反転しない場合、AI だけでどこまで行けるか

結論から言うと 「verifiedPhysical を true にする」以外は全部行けます。

§1-1（verifiedPhysical のゲート定義）— 100% 行ける

測定が 1 件も無くても、ゲートは書けます。むしろ測る前に書くべきものです。

作れるもの測定が要るか
合格条件の条文（何を・何点・どの許容差で・誰の記録で）要らない
記録を読んで真偽を返す判定器（リテラル false を廃止する）要らない
記録が 0 件のとき false を返すことの変異試験要らない
記録が揃ったとき true を返すことの試験（合成の記録を入れて確かめる）要らない
実物の記録で true になること要る ← ここだけ止まる

合成の記録でゲートを試験できます。「実測記録が 4 件そろえば true」という条文なら、 架空の 4 件を作れば判定器の動作は全部確かめられます。 止まるのは「本物の記録が入る」ところだけで、それは 1 行の差分です。

これは反転してもしなくてもやる価値があります。現状の verifiedPhysical は

scripts/exportHalfPlugProfile.ts:612 のリテラルで、誰かが書き換えれば true になります。

測定が永久に来なくても、リテラルのままにしておく理由はありません。

§1-6（受け皿）— 100% 行ける

作れるもの測定が要るか
docs/measurements/ の記録形式を schema にする要らない
validate:profiles の検証対象へ足す（13 → 14 件）要らない
測定シート（分解能・生値 3 回・期待値の印字・ばらつき超過で不合格）要らない
記録から接点位置を逆算する計算（fit:contacts の 4極版）要らない（合成データで試験できる）
測定値を profile へ流し込む経路要らない（合成データで試験できる）
evidenceGrade に測定の区分を足すか決める（→ profile v4・下流が止まる）要らない（判断は要る）

行けないもの — 2 つだけ

1. verifiedPhysical を実物の記録で true にする
2. IV028 の 13.30–13.52 mm を実測値に置き換える

この 2 つ以外は、方針を維持したまま全部終わります。 そして終わらせておけば、測れる人が現れた日に、記録を 1 枚もらうだけで両方閉じます。

方針を維持する場合の唯一の損失は、その「現れる日」がいつか分からないことです。

2026-08-02 に募集を始めてから 2026-08-05 現在まで、提供は 0 件です（3 日間なので当然ですが、

見込みの根拠にもなっていません）。

4. L の 1 点だけを測る最小手順

この手順だけで、モデルと実在部品のどちらが正しいかが決まります。

用意するもの

4極ジャック 1 個            端子にクリップを挟めるもの（THT が楽）
4極プラグ 1 個              CTIA。市販ケーブルを切ってもよい
テスター                    導通ブザー付き
デジタルノギス              0.01 mm 表示

手順

① プラグの 4 本の導体にリード線を出す。 ケーブルを切ったなら被覆を剥くだけです。どれがどの導体かは、まだ分からなくて構いません。

② 完全に挿し込む。プラグ肩がジャック前面に当たるまで。

③ 「プラグの先端（Tip）」と導通するジャックの端子を 1 本だけ見つける。 プラグ側は、先端の金属部分にテスターの片方を当てます（リード線ではなくプラグ先端そのもの）。 もう片方をジャックの端子に順に当て、ブザーが鳴る端子を探します。 これが L の端子です。端子番号を推測しないでください。

④ プラグを完全に抜く。

⑤ テスターを ③ で見つけた組み合わせにつないだまま、プラグをゆっくり挿す。 ブザーが鳴った瞬間に止める。行き過ぎたら抜いてやり直してください（戻して合わせない）。

⑥ その状態で、プラグ肩とジャック前面のすき間をノギスで測る。

    ┌─ プラグ肩
    │        ┌─ ジャック前面
    ▼        ▼
 ━━━┓  ←→  ┃
    ┃ すき間 ┃━━━━━━  ← 挿さっているプラグ
 ━━━┛      ┃

⑦ ④〜⑥ を 3 回繰り返し、3 つの値をそのまま書き留める。平均を書かないでください。

読み方 — その場で分かります

測った値意味
2 mm 前後（1.5〜2.8 mm）モデルの仮定が正しい。IV028 はいまの位置でよい
0.7 mm 前後（0〜1.3 mm）実在部品 PS000001 のほうが正しい。IV028 は動く。看板の結論も見直しになる
どちらでもないどちらの予測も外れ。これが一番おもしろい結果です

予測は測る前から公開してあります（artifacts/real_jack_comparison.json の testerPredictions）。 後から結論に合わせることはできません。

5. 決めること

選択肢この文書での扱い
A条件付きで反転する（§0 の ①② を両方満たす測定だけ自分で測る＝いまは L の 1 点だけ）推奨
B全面的に反転する（§1-1 の外径や §1-2 の LED 回路も自分でやる）勧めません。方針の理由が実際に当てはまります
C維持する（募集のまま）損失は §3 の 2 行だけ。それ以外は同じだけ進みます

A を勧める理由は、L の 1 点が「精度の要る測定」ではないからです。 145 倍の差を見る作業を、精度が要るという理由で断るのは、理由と対象が噛み合っていません。

C でも構いません。その場合 AI 側は §3 の表を全部やって、 記録が 1 枚来た日に閉じる状態まで持っていきます。待つ場所が変わるだけです。

  • [人間] A / B / C を選ぶ
  • [AI] 選ばれた案に合わせて VERIFICATION_PLAN.md の冒頭 blockquote を書き換える差分を出す
  • [AI] A なら §0 の ①② を条文へ書き、各測定を当てはめた表を VERIFICATION_PLAN へ入れる
  • [AI] どの案でも §3 の表は全部やる（方針に依存しない）
