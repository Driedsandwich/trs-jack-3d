感度解析 — どの結論が揺れないか

この文書の HTML 版（同名 .html）は npm run docs:html で生成しています。HTML を直接編集しないでください。

作成 2026-08-01 ／ 再現コマンド npm run sensitivity ／ 生データ artifacts/sensitivity.json

このプロジェクトは実物と突き合わせていません（VERIFICATION_PLAN.md）。 その状態で「11.77 mm で橋絡する」と単一の数字を出すのは、意味が強すぎます。

そこで、仮定として置いたパラメータを成立範囲いっぱいに振り、 何が不変で何が動くかを機械的に測りました。3極（§2–§3）と 4極（§4）の両方でやっています。 結論は「仕組みは揺れない、深さの数字は揺れる」です。

すると、「Tip 導体を含む橋絡は起きない」という結論がその上限の言い換えになり、

検証になりません（循環します）。そこで段差の 2 倍まで振って、

やり方は 2 通りです。

  • 一つずつ振る（OAT） … 各パラメータを 41 段階、他は既定値。7 × 41 = 287 通り
  • 同時に振る … 7 個すべてを 3 水準で総当たり。3⁷ = 2,187 通り

同時振りをやるのは、OAT だと「一つずつなら平気だが、組み合わせると壊れる」を見逃すためです。 乱数は使っていないので、何度実行しても同じ結果になります。

2. 揺れない結論（3極）

2-1. Tip 導体を含む橋絡は起きない

これがこのプロジェクトの中心的な主張で、感度解析でも揺れませんでした。

確認結果
OAT（compliance 以外の 6 パラメータ、246 通り）Tip 橋絡 0 件
同時振りのうち compliance < 0.15 mm（729 通り）Tip 橋絡 0 件
Tip 橋絡が始まる compliance0.15375 mm

そして 0.15375 という値には意味があります。Tip 導体の最大半径 1.600 と Ring / Sleeve の 1.750 の差、ちょうど 0.150 mm の直上です。

これは偶然ではなく、計算式からそのまま出ます。接点はパッド内で一番高い面 （Ring の 1.750）に押し上げられ、そこから compliance だけ低い面までしか届きません。 Tip 面（1.600）に届く条件は 1.600 ≥ 1.750 − compliance、つまり compliance ≥ 0.150。 パッド幅にも接点位置にも一切依存しません。

つまり「第1絶縁帯で橋絡しない」は、**仮定を選んだ結果ではなく、

図面記載の φ3.20 と φ3.50 という 2 つの FACT から出る幾何的な帰結**です。

採用している compliance 0.05 は、しきい値 0.154 の 1/3 です。

2-2. 橋絡するのは Ring↔Sleeve だけ

完全挿入が成立する全構成で、観測された橋絡は RING+SLEEVE のみでした （compliance を 0.15 以上に上げた構成を除く）。

2-3. Tip 接点・Ring 接点は橋絡に関与しない

tip.axialCenter / ring.axialCenter / tip.padWidth / ring.padWidth の 4 つをどう振っても、橋絡の深さは 11.77 mm から動きません（幅 0.00）。

橋絡を起こしているのは帰線（Sleeve）接点だけなので、当然ではありますが、 「橋絡の数字は帰線接点の仮定だけに依存する」と言い切れることには意味があります。 不確かさの発生源が 2 つに絞れます。

4. 4極（TRRS）

当初は「4極ジャックの接点位置は一次図面が無く全面的に仮定なので、振っても 仮定の分だけ動くだけではないか」と考えていました。やってみると違いました。

3極で効いた不変条件は、ジャック側の仮定ではなくプラグ側の FACT から出ていました。 4極でもプラグ側は FACT（2 社の図面記載寸法）なので、同じ論法がそのまま通ります。

振ったのは 7 個（Tip / Ring1 / Ring2 / Sleeve の各軸位置、狭パッド幅、帰線パッド幅、追従量）で、 同時振り 3⁷ = 2,187 通りです。

4-1. プラトー間隔は 3 本とも 0.700（FACT）

4極プラグは半径 1.750 の平坦面を 3 本（Ring1 / Ring2 / Sleeve）持ち、 その間隔は 0.700 と 0.700。図面記載の絶縁帯幅 0.7 とそのまま一致します。 接点位置とは無関係に決まる値です。

artifacts/sensitivity.json にはこれが 0.701 と記録されています。

プロファイルを 0.001 mm 刻みで走査して平坦面の端を拾っているので、

刻み 1 つぶん広く出ます。真値は導体境界の差そのもの（8.5 − 7.8 = 0.700）です。

4-2. Tip を含む橋絡は起きない（3極と同じ）

確認結果
同時振り 2,187 通りのうち compliance < 0.15 の 729 通りTip 橋絡 0 件

根拠は 3極と同一です。Tip の最大半径 1.600 は他の 3 本（1.750）より 0.15 mm 低く、 届く条件 compliance ≥ 0.150 はパッド幅にも接点位置にも依存しません。

4-3. 橋絡するかどうかは、パッド幅だけで決まる

各接点について、最も橋絡しやすい深さ（パッド中心が絶縁帯の中心に来る位置）で パッド幅を 0.001 mm 刻みに変えて、橋絡し始める幅を測りました。

接点またげる絶縁帯両側の導体橋絡し始めるパッド幅
Ring2 接点Ring1↔Ring2どちらも 1.7500.721 mm（位置 5 通りすべてで同じ）
帰線接点Ring2↔Sleeveどちらも 1.7500.721 mm（位置 3 通りすべてで同じ）
Ring1 接点Tip↔Ring1 のみTip が 0.15 低いどのパッド幅でも橋絡しない（0.600〜0.900 を 0.001 刻みで確認）
Tip 接点なし（先端側に絶縁帯が無い）—橋絡しない

0.721 は偶然ではありません。プラトー間隔 0.700 + 導通とみなす最小重なり 0.01 × 2 = 0.720 の直上です。接点をどこに置いても同じ値になります。

採用値は狭パッド 0.5（< 0.721 なので橋絡しない）、帰線パッド 0.9（> 0.721 なので橋絡する）。 この 2 つの大小関係だけで、4極ジャックの橋絡の有無が決まっています。

4-4. どの接点がどこで橋絡できるかは、FACT だけで決まる

各接点は「完全挿入でパッド全幅が自分の導体に収まる」という制約を受けます。 完全挿入は最も深い位置なので、この制約は同時に 「パッドは自分の導体の奥端を越えられない」ことを意味します。

一方、挿入の過程では、接点はプラグ先端から自分の最終位置まですべてを通過します。 したがって各接点がまたげるのは、自分の導体より先端側にある絶縁帯のすべてです。

Tip 0–4.8 │ INS1 │ Ring1 5.5–7.8 │ INSM │ Ring2 8.5–10.8 │ INS2 │ Sleeve 11.5–14.0
            4.8–5.5              7.8–8.5                10.8–11.5
            Tip が低い→不可       同じ高さ→可            同じ高さ→可

  Tip 接点   … またげる絶縁帯なし            → 橋絡しない
  Ring1 接点 … INS1 のみ                     → 橋絡しない（Tip が低い）
  Ring2 接点 … INS1, INSM                    → INSM で橋絡しうる
  帰線接点   … INS1, INSM, INS2              → INSM と INS2 で橋絡しうる

同時振り 2,187 通りで実際に観測された組み合わせは、この表とちょうど一致しました。

接点観測された橋絡の組
Ring1 接点RING+TIP のみ
Ring2 接点RING+TIP / RING+RING2
帰線接点RING+TIP / RING+RING2 / RING2+SLEEVE

自分の導体より奥の絶縁帯をまたいだ例は 1 件もありません。 そして RING+TIP が出るのは compliance を 0.15 mm 以上にした構成だけで、 0.15 未満の 729 通りでは 0 件でした（§4-2）。

4-5. 混挿（3極プラグ × 4極ジャック）

ここだけは接点位置の仮定に依存します。ただし、依存の度合いは小さいことが分かりました。

4極ジャックの Ring2 接点の軸位置を成立範囲 3.45〜5.25 いっぱいに 41 分割して振ると、 完全挿入での行き先は次のとおりでした。

Ring2 接点の行き先件数
3極プラグの Sleeve（＝帰線が正しくつながる）40 / 41
絶縁帯の上（未接続）1 / 41（範囲の端 5.25 のみ）

つまり「3極ヘッドホンを 4極ジャックに挿すと、音は正常でマイクだけ未接続」という 結論は、接点位置をどこに置いてもほぼ成り立ちます。範囲のちょうど端に置いたときだけ、 Ring2 接点が絶縁帯に乗って未接続になります。

5. 読み方

README や REPORT に載せている深さの数字は、帰線接点の位置とパッド幅を 現在の仮定値に固定したときの値です。それらは一次資料に無い仮定なので、 数字は次の幅を持つと読んでください。

事象既定値現実的な幅
帰線接点がプラグ Tip に触れ始める3.93 mm1.2〜5.3 mm
Ring 側ブレーク接点が開く8.06 mm6.9〜9.2 mm
Ring↔Sleeve 橋絡が始まる11.77 mm9.0〜13.1 mm
全接点が正しくつながる12.34 mm11.96〜14.00 mm

一方で、次のことは幅を持ちません。

  • 挿入の途中で、帰線接点がプラグの Tip 導体・Ring 導体の上を順に通過する
  • その過程で、Ring↔Sleeve の橋絡（短絡）が必ず 1 回起きる
  • Tip↔Ring の橋絡は起きない
  • ブレーク接点が開くのは、正しい結線が完成するより前である

「何が起きるか」は決まっていて、「何 mm で起きるか」が決まっていない、という状態です。

6. この解析の限界

  • 4極は CTIA プラグ × 4極ジャックを主対象にしました。OMTP は形状が完全に同一で 機能割当だけが違うので、幾何の結論はそのまま当てはまります（§4 の結果は形状の性質です）。
  • 同時振りは 3極・4極とも各パラメータ 3 水準（各 2,187 通り）です。 範囲の端と中央しか見ていないので、範囲の内側に狭い異常領域があれば見逃します。
  • §4-3 のしきい値は、走査ではなく「最も橋絡しやすい深さ」1 点で測っています。 深さを走査する方法では、走査刻みが答えを変えてしまうためです （0.02 mm 刻みにしたら、同じ構成のしきい値が位置ごとに 0.725 と 0.745 に割れました）。
  • OAT は 41 段階なので、単独パラメータについては同時振りよりも細かく見ています。
  • 同時振りの走査刻みは 0.02 mm です。これより狭い橋絡窓は取りこぼします （既定構成の橋絡窓は 0.17 mm なので、8 点以上に当たります）。
  • 2,187 通りのうち完全挿入が成立したのは 308 通りでした。 パッド幅を導体幅いっぱいまで広げるなど、端の組み合わせでは結線が壊れるためです。 上の「揺れる幅」は、結線が成立する構成だけを対象に集計しています。
  • これは実物の検証ではありません。 モデルの内部で、仮定をどう選び直しても 結論が変わらないことを確かめただけです。実物との照合は依然として VERIFICATION_PLAN.md の手順が必要です。
