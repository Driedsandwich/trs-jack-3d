## 2. **根は 2 つ。そちらは構文 4 つ、こちらは実箇所 6 つを数えました**

**根A。** `{}` は `toString` も `constructor` も**継承しています**。

```

out['__proto__'] = x      → own property にならない（prototype が差し替わる）

`properties` の key は**受け手が決める名前**なので `toString` も来ます。
判定器はそこを分けずに集合差を取っていたので、**項目の追加が見えませんでした。**

**根B。** 打ち切りの鍵が pointer 文字列でした。
`/properties/next/properties/next/…` と**伸び続ける**ので、
同じ節へ戻っても一度も重複しません（実測: 8 段たどって重複 0 件）。

## 3. **`__proto__` は ajv でも真値が出せません**

指摘の 2 件目は `oneOf` の枝で `__proto__` の型を広げる形でした。
**こちらでは ajv が広がりを認めません。**対照行列で切り分けました。

```
schema の properties に置いた key   {"<key>":"x"} を検証   陰性対照 {"zzUnknown":"x"}
  normal                            true                    false
  toString                          true                    false
  constructor                       true                    false
  hasOwnProperty                    true                    false
  valueOf                           true                    false
  __proto__                         **false**               false      ← ajv 自身が拒む
```

`{"__proto__":"x"}` は `JSON.parse` で作れば own property になります
（`Object.keys` に出ます）。それでも **ajv の内部が own key として扱えません。**

**正解器が同じ盲点を持っています。**これは property-based 試験の前提
（「ajv が真値を出す」）が崩れた**初めての例**です。

そこでこの 1 件は**判定器の側だけ**を固定しました（条文 ①-c13 ⑦）。
**ajv の挙動が変わったら試験が落ちる**書き方にしてあります
——「前提が変わった」と分かるようにするためです。

> **正解器の盲点をどう扱うべきか、意見をいただけると助かります。**
> いまは「判定器だけ固定し、前提が変わったら気づく」形にしています。

## 4. **変異対照で 3 か所が「外しても落ちない行」でした**

直した箇所を 1 つずつ戻したところ、**3 か所は消しても全件通りました。**
実害を先に測り、**3 つに分けました。**

```

**A3 は承知のうえで残しました。**A1c が将来戻ったときに効きます。
コードとテストの両方にその申告を書いています。
**「消しても落ちない」を見たとき、安全・精度・falsify 不能のどれかを毎回分ける**

## 5. **P1 の最初の直し方が間違っていました。既存の試験が拾いました**

「一度でも見た節の組」を覚える形にしたところ、**`contractMigration` が 1 件落ちました**
——記録した差分が実物から消えていたのです
（`/properties/nominalConfiguration/properties/windows/items`）。

**同じ節が 2 つの経路から来るとき、2 回目を飛ばしてその経路の差分を出さなかった**からです。

```
「一度でも見たか」            → 別の経路から来た同じ節の結果まで消える
「いま辿っている経路上にあるか」  → 循環だけを止める（正しい）
```

`seen` を**スタック**にし、`finally` で必ず外す形へ直しました。
変異は 2 方向とも落ちます（鍵を pointer へ戻す／戻るときに外さない）。

> **出力が減るだけの欠陥は、落ちる試験が無ければ気づけません。**
> 今回は既存の試験が拾ってくれました。**新しく足した試験だけでは足りない**という例です。
