# v0.6.8 — **schema は 1 本も上げていません。下流はどこでも止まりません**

## ⚠ 先に読むところ

### 1. **v0.6.7 は、生のヘッダの数値欄を `size` しか見ていませんでした**

**受け手に直接影響するのはこちらです。**

```
mode=abc / uid=abc / gid=abc / mtime=abc（checksum は取り直し）
  検算 v12  READ — 「a.txt が source にある」と言う
  bsdtar    exit 0 — a.txt を作る
  python    exit 0 — **黙って a.txt を作らない**（OK と表示して終わる）
  GNU tar   Archive contains 'abc\0    ' where numeric mode_t value expected

checksum 欄が「8 進の頭 + junk」
  検算 v12  READ — 同上
  bsdtar    Damaged tar archive と警告して a.txt を作らない
```

**同じ archive から別の木ができます。**受け手が python で展開すると、
検算器が「あった」と言ったファイルが手元にありません。

`mode` / `uid` / `gid` / `mtime` / `devmajor` / `devminor` は**読んでもいませんでした。**
checksum 欄は前方一致でしか見ておらず、8 進のあとの junk を見逃していました。

### **お願い: v0.6.7 以前で出た `OK` は、ヘッダの数値欄まで見ていません**

**そちらが v0.6.7 以前の道具で別の archive を検算していた場合、
`OK` が出ていても「そのヘッダが正しい」ことは確かめていません。**
`v0.6.8` の道具で取り直してください。

### 2. 宙に浮いた local PAX ヘッダを受理していました

```
全入力のあとに「x: mtime=1」だけを置き、後続 member を置かない
  検算 v12  READ
  bsdtar    exit 1 — Damaged tar archive
  python    exit 2 — ReadError: end of file header
```

v0.6.7 は `path` と `linkpath` にしか pending 状態がありませんでした。
**鍵に関係なく `x` は「次の member を待つ」状態を作ります。**

### 3. **こちらの過剰拒否が 4 版続けてです**

```
directory の PAX path が / で終わる      2 実装とも同じ木を作るのに拒んでいた
PAX の値の先頭ゼロ（uid=0001 など）      同上
歴史的な signed checksum                 同上
backslash を含むパス                     Unix では 3 実装とも同じ木
```

**先頭ゼロは、前回の監査が勧めた正規表現がそのまま過剰拒否になった件です。**
`^-?(0|[1-9][0-9]*)…` を採ったので `uid=0001` が落ちていました。
**勧告を機械的に採ると、その勧告自体が過剰拒否になりうる**——今回それが起きました。

backslash は `ARCHIVE_UNSUPPORTED` に移しました。**壊れているのではなく、
受け手の OS で意味が変わる**からです。

### 4. 確かめる側の欠陥も直しました

- 差分試験は**パスの一覧ではなく型つきの木**（型・指す先・中身のバイト）で比べます。
  v0.6.7 は名前だけを並べていたので、**同じ名前で片方が directory・片方が通常ファイル**でも
  差が出ませんでした。
- **python が無ければ「合格」ではなく失敗**にします。
- 木を歩く道具が**権限 0 のファイルを読めずに落ちて**いました。読めなかった事実を記録します。

## 止める理由が、どちらの実装で裏を取れるか

```
GNU tar 側でだけ根拠が取れる   9 件
bsdtar 側でだけ根拠が取れる    9 件
どちらでも取れていない         3 件
```

**生の数値欄の拒否は、この表に 1 件も残っていません**——どちらかの実装で必ず根拠が取れます。
`none` の 3 件は、名前・指す先の上書きが 2 つ効く形の**片方の順序** 2 件と、
**symlink の名前が `/` で終わる形**です。
