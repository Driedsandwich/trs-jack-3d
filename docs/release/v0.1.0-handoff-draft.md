### 1. 何で固定するか — 2 通りのどちらかにしてください

**`main` を追わないでください。**

| 方法 | 固定するもの |
|---|---|
| **A** | release tag `v0.1.0` ＋ asset の SHA-256（`SHA256SUMS` に同梱） |
| **B** | exact commit `84c39753f70ff49baf3dfd445315d4c4316b0791` ＋ `provenance.inputDigest` |

```
provenance.inputDigest = bba0e6dc73a4273c7178ede2eaeb40cb518fcf6c9c0c7679d24f15a9a6d821a0
profileId              = trs-jack-3d:<variant>:bba0e6dc73a4
```

**`sourceRevision` では固定しないでください。**
artifact を含めてコミットすると HEAD が変わるため、生成時点で正しかった値が
あとから「古い」ように見えます。`inputDigest` は**入力ファイルの中身だけ**から
作っており、生成物自身を含みません。入力が同じなら、生成し直しても変わりません。

`provenance.inputFiles[]` に path と sha256 が入っているので、**そちらで再計算して
検算できます**（作り方は `inputDigestScope` に書いてあります）。

### 2. `events[].spreadMm` の意味が変わりました（2026-08-03）

**それ以前の版を取り込み済みの場合、`spreadMm` は読み捨ててください。**

旧版は、感度解析の **`kind` 単位の集計を各事象へそのまま複製**していました。
`STATE_CHANGE` は 1 回の挿入で何度も起きます（**TRS×TRRS で 29 件 / TRS×TRS で 24 件**）。
その全部に同じ `−0.88〜14 mm`（挿入ストローク全域）が付いており、
たとえば Ring のブレーク接点にも帰線接点用の幅が付いていました。**下流では誤情報です。**

現在は `spreadStatus` で 3 つを区別します。

| `spreadStatus` | `spreadMm` | 意味 |
|---|---|---|
| `MEASURED` | 値あり | その事象そのものを測った幅 |
| `NOT_EVENT_SPECIFIC` | `null` | `kind` 単位の集計しか無く、この事象へは配れない |
| `NOT_MEASURED` | `null` | 測っていない |

**どれも「動かない」の意味ではありません。**
`kind` 単位の集計は捨てておらず、`sensitivitySummary.aggregateSpreadByKind` にあります。
**そちらを個々の事象へ当てはめないでください。**

### 3. `intervalId` と `eventId` は単独で保存しないでください

どちらも**位置に依存します。**

- `intervalId`（`IV028` など）は区間の並び順から振った番号です
- `eventId`（`STATE_CHANGE:JC_RING:BREAK_CLOSED->BREAK_OPEN#1`）の末尾 `#n` は、
  同じ遷移が挿入中に複数回起きるための連番です

モデルが変われば、同じ番号が別の状態を指します。実際、4極ジャックの組み直しで
**TRS×TRRS profile** の本命の区間は `IV019`（12.90〜13.12 mm）から
`IV028`（13.30〜13.52 mm）へ移り、その profile の区間総数も 21 → 30 になりました
（TRS×TRS profile は 23 区間で、こちらには本命の区間がありません）。

**`profileId` とセットで保存し、`profileId` が違ったら
`electricalTopology.topologyClass` と `normalizedStart/End` で引き直してください。**

> `topologyClass` は 2026-08-03 に `acousticAnnotation` から
> **`electricalTopology`** へ移しました（電気的な事実と聴感の仮説を別層にするため）。

### 4. 実測していないことの確認

| | |
|---|---|
| `verifiedPhysical` | **`false`** |
| 導通の実測 | **未実施** |
| 音響の実測 | **未実施** |
| 4極ジャックの接点の軸方向オフセット | **ASSUMPTION**（一次資料なし） |

**実在資料 2 件が逆を指しています。**
pro-SIGNAL PS000001 の断面図（Tip 接点 12.75 mm）を入れると、
左右差分の区間は **1 件も出ません**。Lumberg 1503 28 の端子位置（11.30 mm）では出ます。
結論は Tip 接点が 12.6 mm より浅いことを必要条件にしており、PS000001 はその外側です。
**どちらが実物に近いかは決着していません。**

`realizability.passesPadWidthHeuristic` は**製造可能性の判定ではありません。**
0.3 mm という閾値には出典がなく、`manufacturingVerified: false` と記録してあります。
