## 固定のしかた

**`provenance.inputDigest` で固定してください。**

```
provenance.inputDigest = bba0e6dc73a4273c7178ede2eaeb40cb518fcf6c9c0c7679d24f15a9a6d821a0
profileId              = trs-jack-3d:<variant>:bba0e6dc73a4
generatedFromCommit    = 84c39753f70ff49baf3dfd445315d4c4316b0791
```

`sourceRevision` や `main` で固定しないでください。

- `inputDigest` は**入力ファイルの中身だけ**から作った sha256 です。生成物自身は含みません
- **artifact を含めてコミットすると HEAD は変わりますが、`inputDigest` は変わりません**
- 逆に、寸法を 1 文字でも直せば必ず変わります
- `provenance.inputFiles[]` に path と sha256 が入っているので、**受け取り側で再計算して検算できます**（作り方は `inputDigestScope` にあります）

`intervalId`（`IV028` など）と `eventId` は**位置に依存します**。単独で保存せず、
`profileId` とセットにしてください。

## この profile に**してはいけない**こと

- `acousticAnnotation` をフィルタ係数・ゲイン・クロストーク量へ変換する
- `quality` を接触抵抗 Ω へ換算する
- `topologyClass` を固定の係数行列へ直結する
- 1 機種の mm 値を一般的な「挿入深度」として使う（機種横断では `normalized` を使ってください）
- `events[].spreadMm` が `null` のものを「動かない」と読む（`NOT_MEASURED` /
  `NOT_EVENT_SPECIFIC` は**測っていない**という意味です）
