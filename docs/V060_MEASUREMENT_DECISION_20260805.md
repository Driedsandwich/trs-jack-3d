`docs/VERIFICATION_PLAN.md` の 2026-08-02 方針は**維持します。**

> **メンテナ自身は実測を行いません。**（略）
> **モデルは「未実測のまま」で完結させます。**実測は精度を上げますが、

❌ やらないこと    部品の発注 ／ 自分での測定 ／ 実測値を待つこと
✅ 受け入れること  実測データの提供 ／ 図面や一次資料の情報提供 ／ 手順の誤りの指摘

## 0. **どの測定なら、経験がなくても結果が動かないか**

「精度が要る」は測定ごとに当てはまったり当てはまらなかったりします。
`VERIFICATION_PLAN` の各測定を、**見分けたい差**と**要る技能**の 2 つで並べ直しました。

| 測定 | 見分けたい差 | 分解能 0.01 mm に対して | 要る技能 |
|---|---|---:|---|
| **§2-2 の `L` 1 点** | すき間 **2.14 mm** か **0.69 mm** か | **145 倍** | **導通が鳴った位置で止めて測るだけ** |
| §2-2 の GND | 8.33 か 8.67 か | 34 倍 | 同上 |
| §1-1 プラグ外径 | 直径差 **0.30 / 0.23 / 0.090** の 3 本の線。隣り合う線の間隔は **0.07 mm** | **7 倍** | **逆テーパの頂点（先端から 4.3〜4.8 mm）を探して読む** |
| §1-2 橋絡の決着 | 光る／光らない（**寸法ではない**） | — | **LED 回路の自作・プラグへのはんだ付け・一定速度での挿入** |
| §2 深さの確認 | すき間 | — | 導通 + すき間（`L` と同種） |
| §2-2 の MIC / R | 0.03 / 0.05 mm | 3〜5 倍 | **測っても差がつかない** |

**`L` の 1 点だけは、145 倍離れた 2 つの予測のどちらかを選ぶ作業です。**
ノギスを 0.1 mm 単位で雑に読んでも **14.5 倍**あり、**結論は動きません。**
**測り慣れていない方でも、結果が読み手の腕に依存しません。**

一方 §1-1 は隣り合う判定線が **0.07 mm**（7 倍）しかなく、しかも
**逆テーパの頂点を自分で探す**必要があります。当て方のクセがそのまま結論を変えます。
§1-2 は寸法ではありませんが、**LED 回路を自作して一定速度で挿す**という別の技能が要ります。
**この 2 つは、計測に慣れた方にお願いしたい測定です。**

> **線引きは 2 条件の AND で書けます。**
>
> ```
> ① 見分けたい差が、道具の分解能の 100 倍以上ある
> ② 道具の当て方・回路の自作・速度制御などの技能を要しない
> ```
>
> **`L` は ①②とも満たします。§1-1 は ① で落ち、§1-2 は ② で落ちます。**
> 募集するときは、**この 2 条件を満たす測定を先に出す**と応じてもらいやすくなります。

## 1. 測ってくださる方の作業量 — **1 時間・部品代 ¥400〜1,200**

`L` の 1 点だけに絞った場合です。**手元に部品がある方なら、買い足すものはほぼありません。**

| # | 工程 | 時間の目安 | **つまずきやすい箇所** |
|---|---|---|---|
| 1 | 4極ジャックと 4極プラグを用意する（→ §2） | — | **端子配列がデータシートに無い品だと、工程 3 が倍になります** |
| 2 | プラグの 4 導体にリード線を出す | 20 分 | **隣の導体と短絡させやすい。**被覆を剥きすぎないこと |
| 3 | 完全挿入して「プラグ先端と導通する端子」を 1 本だけ特定する | 10 分 | **端子番号を推測しないでください。**導通で決めます |
| 4 | プラグをゆっくり挿し、その端子が最初に導通した位置で止める | 5 分 ×3 回 | **速く挿すと行き過ぎます。**戻して合わせない（挿入方向だけ） |
| 5 | プラグ肩とジャック前面のすき間をノギスで測る | 5 分 ×3 回 | **斜めに当てない。**同じ当て方を 3 回繰り返す |
| 6 | 3 回の値と分解能をシートへ書き写す | 5 分 | **平均だけ書かないでください。**生値を 3 つとも残します |
| | **合計** | **約 1 時間** | |

**工程 6 で終わりです。**判定・計算・profile への反映・再生成は、こちらで機械にやらせます。
**「合っていたか」の判断も渡しません**（期待値はシートに先に印字されていて、
一致したかどうかは機械が言います）。

### 要るもの

| | 品目 | 概算 |
|---|---|---|
| 部品 | 4極ジャック（→ §2） | ¥100〜500 |
| 部品 | 4極プラグ または CTIA 4極ケーブル | ¥300〜700（Lumberg 1532 02 なら $3.62 + 送料） |
| 測定器 | デジタルノギス 0.01 mm | ¥2,000〜4,000（**お持ちならこれで足ります**） |
| 測定器 | テスター（導通ブザー付き） | ¥1,500〜3,000（同上） |
| | **部品だけなら** | **¥400〜1,200** |

> **ジャックは基板に付けずに測れます。**端子にクリップを挟むだけです。
> ただし SMT 品は端子が小さくクリップが滑るので、**THT（スルーホール）品のほうが楽**です。

## 3. **提供が無いままでも、どこまで行けるか**

結論から言うと **「`verifiedPhysical` を `true` にする」以外は全部行けます。**
**だから募集は「お願い」であって、こちらの前提ではありません。**

### §1-1（`verifiedPhysical` のゲート定義）— **100% 行ける**

測定が 1 件も無くても、**ゲートは書けます。**むしろ測る前に書くべきものです。

| 作れるもの | 測定が要るか |
|---|---|
| 合格条件の条文（何を・何点・どの許容差で・誰の記録で） | **要らない** |
| 記録を読んで真偽を返す判定器（リテラル `false` を廃止する） | **要らない** |
| 記録が 0 件のとき `false` を返すことの変異試験 | **要らない** |
| 記録が揃ったとき `true` を返すことの試験（**合成の記録**を入れて確かめる） | **要らない** |
| **実物の記録で `true` になること** | **要る** ← ここだけ止まる |

**合成の記録でゲートを試験できます。**「実測記録が 4 件そろえば true」という条文なら、
**架空の 4 件を作れば判定器の動作は全部確かめられます。**
止まるのは「本物の記録が入る」ところだけで、**それは 1 行の差分です。**

> **これは提供が来なくてもやる価値があります。**現状の `verifiedPhysical` は
> `scripts/exportHalfPlugProfile.ts:612` のリテラルで、**誰かが書き換えれば `true` になります。**
> 提供が永久に来なくても、**リテラルのままにしておく理由はありません。**

### §1-6（受け皿）— **100% 行ける**

| 作れるもの | 測定が要るか |
|---|---|
| `docs/measurements/` の記録形式を schema にする | **要らない** |
| `validate:profiles` の検証対象へ足す（13 → 14 件） | **要らない** |
| 測定シート（分解能・生値 3 回・期待値の印字・ばらつき超過で不合格） | **要らない** |
| 記録から接点位置を逆算する計算（`fit:contacts` の 4極版） | **要らない**（合成データで試験できる） |
| 測定値を profile へ流し込む経路 | **要らない**（合成データで試験できる） |
| **`evidenceGrade` に測定の区分を足すか決める**（→ profile v4・下流が止まる） | **要らない**（判断は要る） |

### 行けないもの — **2 つだけ**

```
1. verifiedPhysical を実物の記録で true にする
2. IV028 の 13.30–13.52 mm を実測値に置き換える
```

**この 2 つ以外は、方針を維持したまま全部終わります。**
そして終わらせておけば、**測れる人が現れた日に、記録を 1 枚もらうだけで両方閉じます。**

> **「現れる日」がいつかは分かりません。**2026-08-02 に募集を始めてから 2026-08-06 現在まで、
> **提供は 0 件**です（4 日間なので当然ですが、見込みの根拠にもなっていません）。
> **だから工程に入れません**（→ `V060_PLAN` §4）。来たら閉じる、来なければ `false` のままです。

## 4. **`L` の 1 点だけを測る最小手順**

**この手順だけで、モデルと実在部品のどちらが正しいかが決まります。**

### 用意するもの

```
4極ジャック 1 個            端子にクリップを挟めるもの（THT が楽）
4極プラグ 1 個              CTIA。市販ケーブルを切ってもよい
テスター                    導通ブザー付き
デジタルノギス              0.01 mm 表示
```

### 手順

**① プラグの 4 本の導体にリード線を出す。**
　ケーブルを切ったなら被覆を剥くだけです。**どれがどの導体かは、まだ分からなくて構いません。**

**② 完全に挿し込む。**プラグ肩がジャック前面に当たるまで。

**③ 「プラグの先端（Tip）」と導通するジャックの端子を 1 本だけ見つける。**
　プラグ側は、**先端の金属部分**にテスターの片方を当てます（リード線ではなくプラグ先端そのもの）。
　もう片方をジャックの端子に順に当て、**ブザーが鳴る端子**を探します。
　**これが `L` の端子です。端子番号を推測しないでください。**

**④ プラグを完全に抜く。**

**⑤ テスターを ③ で見つけた組み合わせにつないだまま、プラグをゆっくり挿す。**
　**ブザーが鳴った瞬間に止める。**行き過ぎたら抜いてやり直してください（戻して合わせない）。

**⑥ その状態で、プラグ肩とジャック前面の**すき間**をノギスで測る。**

```
    ┌─ プラグ肩
    │        ┌─ ジャック前面
    ▼        ▼
 ━━━┓  ←→  ┃
    ┃ すき間 ┃━━━━━━  ← 挿さっているプラグ
 ━━━┛      ┃
```

**⑦ ④〜⑥ を 3 回繰り返し、3 つの値をそのまま書き留める。**平均を書かないでください。

### 読み方 — **その場で分かります**

| 測った値 | 意味 |
|---|---|
| **2 mm 前後**（1.5〜2.8 mm） | **モデルの仮定が正しい。**`IV028` はいまの位置でよい |
| **0.7 mm 前後**（0〜1.3 mm） | **実在部品 PS000001 のほうが正しい。**`IV028` は動く。看板の結論も見直しになる |
| どちらでもない | **どちらの予測も外れ。**これが一番おもしろい結果です |

**予測は測る前から公開してあります**（`artifacts/real_jack_comparison.json` の `testerPredictions`）。
**後から結論に合わせることはできません。**

### 書き留める形

```
ジャックの型番      :
プラグの型番        :
ノギスの分解能      : 0.01 mm
すき間 1 回目       :      mm
すき間 2 回目       :      mm
すき間 3 回目       :      mm
測定日              :
```

測った人・部品のロット・使った測定器も一緒にいただけると、記録として追えるようになります。

- **[AI]** これを `docs/measurements/` の記入シートとして用意する（判定欄も自動で出す）
- **測ってくださる方**は、数字を書き写すだけで終わりです。**判断は渡しません**
